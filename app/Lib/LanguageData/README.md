Language names and ISO 639-3 codes were generated from ICU locale data. Plural defaults use GNU gettext and Translate's localisation guide:

https://github.com/translate/l10n-guide/blob/master/docs/l10n/pluralforms.rst
https://www.gnu.org/software/gettext/manual/html_node/Plural-forms.html

This bundled reference is optional: administrators may add other three-letter codes and supply their own plural rules. An empty plural_forms value means no rule was verified; the form requires a manual rule. No ICU, gettext executable, or network access is needed at runtime.
